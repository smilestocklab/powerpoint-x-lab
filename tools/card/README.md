# 投稿カード画像の生成

X投稿に添付するカード画像（1200×675）を、HTMLテンプレートから生成します。外部の画像生成サービスは使いません。同じテンプレートから作るので、毎回まったく同じデザインで量産できます。

## 生成タイミング

**実機検証が終わってから**です。カードには `⏱` の実測値が入るので、検証前には作れません。

```
朝7時 Routine: 下書き生成 → Slack + メール通知
      ↓
あなた: PowerPointで実機検証、Before/Afterの所要時間を実測
      ↓
カード画像を生成 ← ここ
      ↓
Xへ手動投稿
```

## 2種類のレイアウト

| `--layout` | テンプレート | 用途 |
|---|---|---|
| `timing`（既定） | `template.html` | Before/Afterの時短比較。柱①〜④ |
| `quip` | `template-quip.html` | ふきだし型。時短の数字が無い柱⑤「あるある・小ネタ」 |

`quip` は時短バーを持たないため、**上の「生成タイミング」の制約を受けません**（実測値が不要なので検証前でも作れます）。ただし内容の正確性は別途確認してください。

## 使い方（timing）

`make_card.py` に値を渡すだけです。フォントの取得もバー幅の計算も自動で行われます。

```bash
python3 tools/card/make_card.py \
  --pillar shortcut \
  --label "PowerPoint 時短Tips" \
  --no "#01" \
  --key "F4" \
  --headline1 "直前の操作を、" \
  --headline2 "もう一度" \
  --before-name "リボンから毎回変更" --before-sec 12 \
  --after-name "F4 を押すだけ" --after-sec 2 \
  --note "図形10個の色を変える場合" \
  --account "@your_account" \
  --out card.png
```

### 引数

| 引数 | 内容 |
|---|---|
| `--layout` | `timing`（既定） / `quip` |
| `--pillar` | 柱に対応する配色。`shortcut` / `verify` / `light` |
| `--label` | ピルのラベル（例: PowerPoint 時短Tips） |
| `--no` | テーマ番号（themes.md の # と対応） |
| `--key` | ショートカットキー・機能名（例: F4） |
| `--headline1` | 見出し1行目 |
| `--headline2` | 見出し2行目。アクセント色になる（省略可） |
| `--before-name` / `--before-sec` | Before の操作名と実測秒数 |
| `--after-name` / `--after-sec` | After の操作名と実測秒数 |
| `--note` | 計測条件（例: 図形10個の色を変える場合） |
| `--account` | アカウント名 |
| `--out` | 出力先PNG |
| `--scale` | `2` で2400×1350の高解像度 |

**秒数は必須です。** 実機検証を終えていないと値が入らないので、これがそのまま検証ゲートとして働きます。

バー幅は `長いほう=560px` として実測値に厳密比例させた値が自動計算されます。手で計算する必要はありません。

## 使い方（quip）

```bash
python3 tools/card/make_card.py --layout quip \
  --pillar light \
  --label "資料作成あるある" \
  --no "#20" \
  --line1 "自分のPCでは完璧だったのに、" \
  --line2 "先方のPCで開いた瞬間" \
  --line3 "フォントが全部変わってる" \
  --punch "分かる方、そっと「いいね」を押していってください。" \
  --out card.png
```

| 引数 | 内容 |
|---|---|
| `--line1` 〜 `--line3` | ふきだしの本文。2行目以降は省略可 |
| `--accent-line` | アクセント色にする行番号。既定は最終行（オチを目立たせる） |
| `--punch` | ふきだし下の一言。省略可 |

`--pillar` `--label` `--no` `--account` `--out` `--scale` は timing と共通です。

### quip レイアウトの設計意図

- **ふきだし**は timing版のキーの箱と同じ `surface2` / 角丸16px / ヘアラインで、同じデザイン一族に見えるようにしています
- 左端のアクセントバーと尻尾で「誰かの声」であることを示し、共感を誘う形にしています
- **オチの行だけアクセント色**にして、視線が最後に着地するようにしています
- 本文は3行までを想定。それ以上入れると縦がはみ出します（下の「レイアウト上の注意」参照）

### 依存

- **Chromium**: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`（この環境に同梱）
- **Noto Sans JP**: 無ければ `npm install @fontsource/noto-sans-jp` を自動実行します

`node_modules/` と中間ファイル `_build.html` は `.gitignore` 済みです。

### テンプレートを直接編集する場合

デザイン自体を変えたいときは `template.html` を編集します。`make_card.py` はテンプレート内の既定値を文字列置換しているので、置換対象の記述（`<div class="key">F4</div>` など）を変えるとスクリプトが停止します。その場合は `make_card.py` の `subs` も合わせて更新してください。

## デザインの決めごと

**地の色・作法は SMILESTOCK.LAB サイトの `:root` をそのまま踏襲しています。**

| 変数 | 値 | 用途 |
|---|---|---|
| `--bg` | `#2e2e2e` | 地 |
| `--surface` | `#383838` | Beforeバー |
| `--line` | `rgba(255,255,255,.12)` | ヘアライン境界 |

角丸16px / ピル型999px / Noto Sans JP / 135°グラデーションも、すべてサイトから継承しています。

### 柱ごとの配色

`<body data-pillar="...">` を切り替えるだけで色が変わります。サイトと同じ `accent`（塗り）/ `accent2`（グラデ終点）/ `accent-soft`（文字用）の3段構成です。

| `data-pillar` | 対象の柱 | accent | accent2 | accent-soft |
|---|---|---|---|---|
| `shortcut` | ①ショートカット・時短Tips + ②Before/After | `#6a4cff` | `#3f42ff` | `#a994ff` |
| `verify` | ③検証ログ | `#a6e22e` | `#82b224` | `#c3e88d` |
| `light` | ④地味だけど効くTips + ⑤あるある・小ネタ | `#ff00ff` | `#cc00cc` | `#ff6bff` |

紫とライムはサイトから（ホーム / お問い合わせ・計算ページ）。マゼンタは新規色です。

なおサイト全体を検索した結果、**黄色は存在しません**。定義されているのは地の色（`#2e2e2e` `#383838` `#1a1a1a` `#222222`）、ライム系、紫系、それに計算ページの状態色（`#ffb74d` 警告 / `#4caf7d` 成功 / `#6dffb0` / `#ff9090`）だけです。黄色に見えるのは `#a6e22e`（ライム）です。

⚠️ **`--accent` を地の上の文字色に使わないこと。** `#6a4cff` は2.57:1、`#ff00ff` は4.21:1で、いずれもWCAG基準を下回ります。現在のデザインでは `--accent` は塗り（バー・帯・ピルの下地）にしか使っておらず、文字が乗ることはありません。文字には必ず `--accent-soft` を使ってください（3色とも4.5:1以上を確認済み: 紫5.26 / ライム9.59 / マゼンタ5.56）。サイト自体も同じ使い分けをしています。

### その他の決めごと

- **時短の数字が主役**。見出しより視覚的重量を上げてある。これがこのアカウントの差別化の核
- **数字はバーの外に置く**。バー内に入れると、短いバーで文字が溢れます（一度これで失敗しています）
- 色だけで情報を伝えない（バーの長さでも時短が伝わる）
- コントラストはWCAG AA以上、最小文字サイズ22px

## レイアウト上の注意

両テンプレートとも、縦方向は `justify-content: space-between` ではなく**固定余白**で組んでいます。space-betweenはビューポート高さに依存してフッターが描画されない事象があったためです。

**要素を増減するときは margin の合計が675pxを超えないよう調整してください。** 超えると下端の要素（多くはフッター）が静かに消えます。エラーにはならないので、書き出したPNGを必ず目視確認すること。quip レイアウトで本文を4行以上にすると、これに該当します。

## 注意

- 「PowerPoint」はMicrosoftの登録商標です。ロゴ・ブランドカラーは使っていませんが、Microsoft公式と誤認させない配慮をしてください（プロフィールに非公式である旨を記載するなど）
- X投稿時は画像のaltテキストを設定してください
