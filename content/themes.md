# 投稿テーマ バックログ

コンテンツの柱ごとに整理した初期テーマ一覧です（20本）。CLAUDE.mdで定めた比率目安（①②=5〜6割、③=2〜3割、④⑤=1〜2割）に沿って作成しています。

「状態」は次のパイプラインで更新します（Slack自動配信Routineが②を担当、①③④は人が行う）。

1. **未使用** — まだ下書きにしていない
2. **下書き済み** — Slack `#powerpoint-x-drafts` に下書きを配信済み。レビュー待ち
3. **投稿済み** — X本番に投稿済み
4. **保留** — 内容NG・要修正などで見送り

投稿済みのものも、数ヶ月後に表現を変えて再利用してOKです（CLAUDE.mdの運用方針参照）。
